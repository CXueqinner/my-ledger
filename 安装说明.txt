我的生活账本 · iPhone PWA 安装说明

1. 将此文件夹全部文件部署到支持 HTTPS 的静态网站（例如 GitHub Pages）；不能仅在 iPhone 上打开 HTML 文件就获得完整 PWA 离线体验。
2. iPhone 使用 Safari 打开部署后的网址。
3. 点击 Safari 分享菜单 → 添加到主屏幕 → 打开为网页 App → 添加。
4. 从桌面图标打开，首次联网加载后可在离线时继续记账。
5. 每月打开「设置」导出 JSON 备份，并保存到 iCloud 云盘。清理网站数据、删除应用、换手机可能导致原有记录丢失。

GitHub Pages 部署（公开静态页面，不需要上传私人账本数据）：
- 在 github.com 创建一个仓库，上传此文件夹中的五个文件（保留 index.html 在仓库根目录）。
- 仓库 Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
- 打开生成的 HTTPS 地址，然后执行上面的 Safari 添加步骤。
- 注意：GitHub Pages 所部署的网页代码可公开访问；本应用的账单默认只保存在设备本地，不会自动上传仓库或网站。但请勿把包含账单数据的备份 JSON 上传到仓库。

记账口径：
- 银行卡/微信/支付宝消费发生时记支出；信用卡刷卡不记，实际还款时记支出。
- 每月底在「资产」页面录入江苏银行、工商银行、支付宝、微信的资产总额（含理财市值）。
- 宾馆 A 原始投资 35,000 元，宾馆 B 57,500 元，共 92,500 元，计入个人总资产参考值；不显示预计分红。
- 分红到账时在「记一笔」选择收入 → 宾馆A分红 / 宾馆B分红。

注意：总资产是历史成本口径的参考值，尚未扣除信用卡负债及房贷等；不等于净资产或可随时支配的现金。
